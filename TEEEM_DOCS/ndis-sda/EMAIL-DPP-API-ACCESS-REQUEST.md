# Email: NDIA Digital Partnership Program API Access Request

## To
DPO@ndis.gov.au

## Subject
API Access Request — TEEEM Property Management Platform (SDA Provider Software)

## Body

Dear Digital Partnership Office,

We are writing to request API access through the NDIA Digital Partnership Program for our software platform, TEEEM.

### About TEEEM

TEEEM is a property and project management platform used by Australian builders, property managers, and SDA providers to manage their portfolios, tenancies, compliance documentation, and financial operations.

We are developing dedicated SDA (Specialist Disability Accommodation) modules to help registered providers streamline dwelling management, compliance tracking, and payment claims — reducing administrative burden and improving accuracy.

Website: https://teeem.au

### Requested API Access

We are seeking access to the following NDIA APIs:

1. **Payment Claims API** — To enable SDA providers to submit and track payment claims directly from their property management system, eliminating manual portal entry and reducing claim rejection rates from data entry errors.

2. **Service Bookings API** — To create and manage service bookings programmatically, keeping provider systems synchronised with NDIA records.

3. **Participant Verification API** (if available) — To verify participant NDIS numbers and plan details during tenancy setup, ensuring claims are submitted against valid, active plans.

### Use Case

Our SDA provider clients currently spend significant time manually entering claim data into the myplace provider portal. Key pain points include:

- Re-entering property and participant data that already exists in their management system
- Manual calculation of SDA daily rates, pro-rata amounts, and GST
- Delayed discovery of rejected claims
- Difficulty reconciling NDIS payments with accounting systems

With API access, TEEEM would:

- Auto-populate claim data from existing property and tenancy records
- Apply current SDA Price Guide rates automatically
- Submit claims in bulk for entire portfolios
- Provide real-time claim status tracking
- Reconcile payments with accounting systems (Xero integration)

### Provider Partnership

We are partnering with registered SDA providers who will be the data custodians and authorise API transactions on their behalf. We can provide details of our partner providers upon request.

### Security & Compliance

We are committed to meeting all DPP security requirements:

- All API communications over TLS 1.2+
- OAuth 2.0 authentication
- Complete audit trail of all API transactions
- Data handling compliant with the Privacy Act 1988 and NDIS Act 2013
- Annual security assessments as required
- Data hosted in Australian data centres

### Next Steps

We would welcome the opportunity to:

1. Complete the DPP application process
2. Undertake the required cyber security assessment
3. Access the sandbox/test environment to begin integration development
4. Discuss any additional requirements or documentation needed

Please let us know the next steps to proceed with our application, and any forms or documentation we need to complete.

Thank you for your time. We look forward to working with the NDIA to improve outcomes for SDA providers and participants.
